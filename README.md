# ZU AI Club Website

Einseitige Website des ZU AI Club an der Zeppelin Universität, Deutsch und Englisch.
Gebaut als Beispiel für den Portfolio-Workshop am 19.11.2026.

Grundlage ist die Vorlage [Story von HTML5 UP](https://html5up.net/story), lizenziert unter
Creative Commons Attribution 3.0 (siehe `LICENSE-html5up.txt`). Schrift: Cabinet Grotesk
von [Fontshare](https://www.fontshare.com/fonts/cabinet-grotesk).
